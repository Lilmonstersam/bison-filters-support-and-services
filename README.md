# Bison Filters — Support & Services Mockup

Interactive mockup for the proposed **Filter Management Services** section on [bisonfilters.com.au](https://www.bisonfilters.com.au/).

## Pages

| Page | Path | Description |
|------|------|-------------|
| Homepage sections | `/` | Hero, homepage services strip (Section A) and industry-page band (Section B) linking to the services detail page. |
| Filter Management Services | `/services/` | Full services page: hero, trust cards, three numbered service steps (kitting, delivery & drop-off, reminders), Why Bison split section, Bison Difference panel, and CTA band. |

## Assets

- `assets/ductwork.jpg` — hero and split-section background (from Figma export)
- `assets/footer-cta.png` — footer CTA banner
- `assets/samedaydespatch.png` — same-day dispatch badge

## Design system

- **Palette**: Primary `#0275D6`, Mid `#2C89D8`, Navy `#00487E`, Dark `#01213C`, Grey `#717171`
- **Typography**: Open Sans (Google Fonts); Scandia fallback for header/footer chrome
- **Components**: Figma trust-card style (radius 16, 16/19/32 shadow), numbered step cards, gradient split section, stat cards

## Deployment

Deployed via GitHub Pages from the `main` branch root. The `.nojekyll` file disables Jekyll processing.
